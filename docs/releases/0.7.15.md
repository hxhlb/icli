- `svc bootstrap` and `svc load` on RootHide rewrite a daemon's plist the way RootHide's own `launchctl` does before launchd reads it: the program and the paths launchd opens (`WatchPaths`, `QueueDirectories`, the standard streams, `WorkingDirectory` and the rest) get the bootstrap root in front, a path under `/rootfs/` loses that prefix, and the file is marked `__Patched`. Before, a plist loaded through icli ran a program and watched directories that do not exist there. The result lists the plists it patched; unloading, rootless and rootful are unchanged.
- `svc paths <plist…>` shows each path launchd will open for a plist, as written and as launchd will see it on this bootstrap, and whether it exists. When only the spelling on the other side of the bootstrap root exists, it says so and suggests what to write. It reads; it changes nothing.
