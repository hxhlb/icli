- `device timezone get` reports the system time zone's Olson name, whether Set Automatically is on, and the offset from GMT. `device timezone set <Olson name>` switches the zone the way Settings does when a city is picked: Set Automatically turns off, and running apps and SpringBoard follow at once without a respring. `device timezone automatic <on|off>` hands the zone back to the system or takes it away. A name that is not a zone is refused and changes nothing. IcliKit exports the same as `timeZone()`, `setTimeZone(_:)` and `setAutomaticTimeZone(_:)`. Contributed by @0xJacky in #2.
