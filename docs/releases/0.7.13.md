- App extensions of a container install are registered on iOS 27 too. There LaunchServices registers apps only through its containerized interface, which takes each plug-in as an info dictionary of its own and ignored the ones nested in the app's, so 0.7.12 fixed iOS 26 and earlier while an iOS 27 install still reported every plug-in in `unregistered_plugins`. The app's plug-ins now follow its own dictionary in the same call; on an iOS 27 guest a packet tunnel provider installed this way launches and connects (Lakr233/vphone-cli#546).
